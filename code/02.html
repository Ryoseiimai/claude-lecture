CODE 02

「このフォルダ何が入ってる？」で
全部説明してくれた

所要時間：約15分 レベル：超入門
この回のゴール
  • フォルダの中身をClaudeに読ませて把握させられる
  • 「今どこにいるか」「どこに移動するか」の操作ができる

1. 「場所」の概念を覚える

Claude Code を起動すると、必ず「どこかのフォルダの中で動いて」います。 人間で言えば「今どの部屋にいるか」のようなもの。この場所のことをカレントディレクトリと言いますが、難しく考えなくていいです。

今いる場所を確認する

pwd

フォルダのパス（住所）が表示されます。たとえば C:\Users\suzuki\Desktop のような感じ。

別の場所に移動する

cd C:\Users\suzuki\Desktop\仕事フォルダ

cd は「ここに移動」という命令です。Macなら cd ~/Desktop/仕事フォルダ のように書きます。

迷子になったら「今どこにいるか教えて」とClaudeに話しかければ教えてくれます。コマンドを覚えなくてもOK。

2. フォルダの中身を読ませる

場所を決めたら、Claudeにフォルダの中身を読ませてみましょう。 

このフォルダを読んで、何があるか教えて

Claudeが中身を一覧にして説明してくれます。このとき、画面上に「ツール使用中」という表示が出ます。これはClaudeが実際にフォルダをのぞいている証拠です。怪しいものではなく、普通の動作です。

フォルダを読ませるだけなら、Claudeがファイルを変更することはありません。安全に試せます。

3. もっと具体的に聞いてみる

フォルダを読ませたあと、こんな質問ができます。

特定のファイルを読んでもらう

このExcelファイルを読んで、中身を教えて

どのファイルが重要か聞く

このフォルダの中で一番重要そうなファイルはどれ？理由も教えて

フォルダ全体を要約してもらう

このフォルダ全体を見て、何のプロジェクトのフォルダか説明して

Claudeは中身を読んで「これは2023年の営業データが入っています。Excelが5つ、PDFが2つあります」のように説明してくれます。

4. こんな場面で使える

仕事の引き継ぎフォルダを把握する

前任者から引き継いだフォルダを全部読み込ませて「このフォルダで何をしていたか教えて」と聞くと、ファイルを一つずつ開かなくても全体像がつかめます。

散らかったデスクトップを整理する前に確認

整理する前に「このデスクトップにある全ファイルをジャンル別に分類して、一覧にして」と頼むと、何がどこにあるか把握できます。

プロジェクトフォルダの棚卸し

「このフォルダの中で、半年以上更新されていないファイルはどれ？」のように条件をつけて質問することもできます。

個人情報や機密情報が入ったファイルを読ませるときは注意してください。Claude Code は Anthropic のサーバーと通信して動きます。社外秘の契約書などは事前に社内のルールを確認してから使いましょう。

5. 試してみよう

  1. ターミナルを開いて claude を起動する
  2. 「今いるフォルダを教えて」と聞いてみる
  3. 「このフォルダを読んで、何があるか教えて」と頼む
  4. 続けて「この中で一番重要そうなファイルはどれ？」と聞く

この4ステップができれば、LESSON 02 はクリアです。

この回のまとめ
  • pwd で今いる場所を確認、cd で移動できる
  • 「このフォルダを読んで、何があるか教えて」でフォルダの中身を把握できる
  • 読んだあと、「重要なファイルはどれ？」など質問を続けられる
  • 引き継ぎ・デスクトップ整理・プロジェクト棚卸しに使える
