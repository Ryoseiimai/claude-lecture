CODE 02

話しかけて
動かしてみる

所要時間:約30分 レベル:基本 必要なもの:Claude Codeインストール済み
この回のゴール
  • Claude Codeでの会話の流れを身につける
  • 「作業する場所」を指定できる
  • 実行確認のダイアログに、落ち着いて対応できる

1. Claude Codeは「話しかけるだけ」

アプリ版と基本は同じです。日本語で話しかければOK。違いは、Claudeがあなたのパソコンで、実際に手を動かすこと。

話しかける → 動く → 結果が返る

例えば、こう話しかける。

デスクトップに「test.txt」というファイルを作って、
中に「こんにちは」と書いて。

Claudeが次のような流れで動きます。

  1. あなたの指示を理解する
  2. 「デスクトップにtest.txtを作成します。いいですか?」と確認
  3. あなたが「yes」と答えると、実際に作成する
  4. 「作りました!」と報告

アプリ版と違って、実際にパソコン上で結果が残ります。 デスクトップを見ると、ほんとにtest.txtができているはず。

2. 作業する「場所」を決める

Claude Codeは「今いるフォルダ」で動きます。 ここをちゃんと意識することが大事。

今どこにいるか確認

ターミナルで:

pwd

現在のフォルダが表示されます。

別のフォルダに移動する

例:Desktopの中の「myproject」フォルダに移動

cd ~/Desktop/myproject
claude

これでmyprojectフォルダで作業できます。 このフォルダの中のファイルを、Claude Codeが自由に読み書きできます。

Windowsの場合の例

cd C:\Users\あなたの名前\Desktop\myproject
claude
迷子になったら「今いるフォルダを教えて」とClaudeに聞けばOK。 「このフォルダの中身を見せて」で、今何があるか確認できます。

3. 最初にやってみる5つの作業

どれも、パソコンのファイルを触る練習です。安全な場所(テスト用フォルダ)でやりましょう。

作業1:ファイルを作る

「test.txt」という名前のファイルを作って、
中身に「テスト」と書いて。

作業2:ファイルを読む

このフォルダにある.txtファイル、全部の中身を見せて。

作業3:ファイルを編集する

test.txtの中身を、「こんにちは、Claude」に変えて。

作業4:フォルダの中を整理する

このフォルダにあるファイルを、種類別(画像/文書/表)の
サブフォルダに分けて整理して。

作業5:簡単な集計

このフォルダにある.csvファイルを全部見て、
合計の行数と、ざっくりの内容を要約して。

4. 実行確認のダイアログにどう対応する?

Claude Codeは、重要な動作をする前に必ず聞いてきます。 これは安全のため。

聞かれる例

ファイル書き換え、削除、コマンド実行など。 こんな画面が出ます。 

Bash コマンド: rm old_file.txt
Description: 古いファイルを削除

  y - 実行する
  n - やめる
  a - いつもこのコマンドを許可

安全な使い方

  • 最初は「y(一回だけ許可)」を基本にする
  • 内容をよく読んでから答える
  • 怪しい動作(大量削除、システムファイル操作)は「n」で止める
  • 信頼できる安全なコマンドだけ「a(いつも許可)」にする
Claude Codeに「危険な設定」で動かさせるのは厳禁。 特に --dangerously-skip-permissions のようなオプションは、プロでも慎重に扱うやつ。 初心者は絶対に使わない。

5. よく使う会話のパターン

パターン1:現状確認

  • 「今のフォルダの中身を一覧にして」
  • 「このプロジェクトが何をするものか、ファイル見て説明して」
  • 「◯◯.txtの中身を見せて」

パターン2:作業依頼

  • 「◯◯のファイルを、こう変えて」
  • 「このフォルダの中のPDFを、全部別のフォルダに移して」
  • 「名前が古い形式のファイルを、新しい形式にリネームして」

パターン3:確認付きの実行

  • 「このファイルの中身を直したい。まず、どう直すか案を見せてから、OK出したら実行して」
  • 「◯◯してほしいけど、実行前に手順を教えて」

「実行前に手順を見せて」と一言添えると、先に計画を見てから安全に進められます。

6. Claudeが「やれない」ことを覚える

Claude Codeにも限界があります。

やれないこと

  • パスワードを必要とするサイトに勝手にログイン
  • あなたが禁止した操作(許可しない、と答えた動作)
  • ネットワーク外部への大きなファイル送信(セキュリティ制約)
  • 物理的な操作(プリンター、カメラなど)

苦手なこと

  • 画像をゼロから作る(描画自体はできない)
  • 音声・動画の編集(一部ツール経由なら可)
  • 大量データの超高速処理(慣れたプロのほうが速い)

7. やってみよう

まずは安全な練習フォルダを1つ作って、試してみましょう。

  1. デスクトップに「claude_test」というフォルダを作る
  2. その中に、test1.txt / test2.txt / test3.txt を自分で3つ作る(中身は適当)
  3. ターミナルで cd ~/Desktop/claude_test して claude 起動
  4. 「このフォルダの中身を見せて」と頼む
  5. 「test1.txtの中身を、『こんにちは』に書き換えて」と頼む
  6. 「3つのファイルの中身を全部連結して、まとめ.txtにして」と頼む

全部できたら、次回はもっと実用的なファイル操作に入ります。

この回のまとめ
  • Claude Codeは、話しかけて → 実行確認 → 動く、の流れ
  • 「今どこで動いてるか」を意識する(pwdで確認、cdで移動)
  • 重要な動作は必ず確認ダイアログが出る。内容を読んで判断
  • 「実行前に手順を見せて」で安全に進められる
  • 危険な設定(--dangerously-skip-permissions など)は絶対に使わない
