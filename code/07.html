外のアプリと
つなぐ

所要時間:約30分 レベル:連携 必要なもの:Claude Code + 連携したいサービスのアカウント
この回のゴール
  • Claude Codeを外部アプリ(Gmail/Notion等)とつなぐ仕組みを知る
  • MCPという接続規格を理解する(名前だけでOK)
  • 自分の仕事ツール1つを、Claude Codeと接続できる

1. アプリ編の「連携」との違い

アプリ編のLESSON 05で、Claude.aiとGmail・Slackの連携を学びました。 Claude Codeでも同じように、外部サービスとつなげます。

この接続の仕組みを、「MCP(エムシーピー)」と呼びます。 専門用語なので、「外の道具につなぐためのコンセント規格」くらいに思っておけばOK。

家電の「プラグ」みたいなもの。 どんなアプリでも、MCP対応のプラグがあれば、Claude Codeに差し込める。

新しいMCPは毎月増えています。自分が使いたいサービス名+「MCP」で検索するとだいたいあります。

3. 接続する前に:APIキーって何?

接続する前に、1つだけ用語を覚えてください。「APIキー」です。

APIキーとは——「あなたの代わりにそのアプリを操作していいですよ」という秘密の合鍵。 家の鍵と同じで、人に渡すと勝手に使われるので、厳重に管理します。 Claude Codeを接続する時は、この合鍵を発行して渡してあげる必要があります。

4. 接続の手順(基本の流れ)

ステップ1:どのアプリとつなぐか決める

最初は1つだけにしましょう。自分が一番使うやつを選ぶ。

ステップ2:そのアプリでAPIキー(合鍵)を発行する

例えばNotionなら、Notion側の設定画面で「インテグレーション」→「新規作成」→APIキーをコピー。 手順が分からなければClaudeに聞けば案内してくれます。 

Notionと接続したい。
Notion側でAPIキー(合鍵)を発行する手順を、画面を見ながら教えて。

ステップ3:Claude Codeに登録する(claude mcp add)

ターミナルに戻って、Claude Code起動中に以下を打ちます。 

/mcp

または、起動前にターミナルで直接: 

claude mcp add notion

聞かれる指示に沿って、さっきコピーしたAPIキーを貼り付け。これで登録完了。 全部Claudeに頼むならこう: 

Notion接続のMCPを追加したい。
claude mcp add notion コマンドの使い方を教えて、

ステップ4:Claude Codeを再起動

一度 /exit で抜けて、もう一回 claude で起動すれば、接続が有効になります。

5. 具体例:GitHub接続

開発者なら、GitHubとの接続は必須級。 ソースコード、Issue、Pull Requestを全部扱えるようになります。

できること

  • 「自分のGitHubにある、今週更新されたリポジトリを一覧で」
  • 「このIssue一覧を、優先度別に整理して」
  • 「最新のPull Requestの変更点を要約」
  • 「このリポジトリに、新しいIssueを作って(内容はこれ)」

6. 具体例:Google Drive接続

できること

  • 「Driveの『提案書』フォルダにあるPDFを全部読んで、要約一覧を作って」
  • 「先月作ったドキュメントで、タイトルに『A社』が入ってるものを探して」
  • 「新しいGoogleドキュメントを作成して、内容はこれ。タイトルは◯◯」

7. 具体例:Slack接続

できること

  • 「#営業チャンネルの今週の動きを、時系列で要約して」
  • 「自分宛てのDMで返信必要なもの、全部ピックアップ」
  • 「新しいメッセージをチャンネルに投稿(内容はこれ、送信前に確認)」

8. 接続する前の注意事項

外部アプリとつなぐ = そのアプリの中身をClaudeが読めるということ。 会社のアカウントを使う時は、必ず会社の規定・上司の許可を取ってください。

APIキーの扱い

  • APIキーは絶対に他人に見せない。Xのポストにスクショ貼る、みたいな事故に注意
  • GitHubなどに設定ファイルを上げる時は、APIキーを含めない工夫を(Claudeに相談)
  • 使わない接続は切っておく

権限の絞り込み

APIキーを発行する時は、必要最小限の権限にする。 「全権限」ではなく「読み取り専用」「特定のチャンネルだけ」などに絞る。

9. 使いこなしのコツ

コツ1:1つ接続したら、まず1週間使い倒す

いっぺんに5個も6個もつなげても、使いきれない。 1つずつ増やして、それぞれの使いどころを自分で見つけるのが最短。

コツ2:接続情報はメモしておく

「何を、どこに、どう接続したか」を別のファイルにメモ。 後で見直しやすくなります。

コツ3:定期的に見直す

月1回くらい、接続一覧を見て「使ってないやつ」は外す。 セキュリティ的にもスッキリします。

10. よくある疑問

Q. APIキーって何?どこでもらう?

A. 各サービスの「開発者設定」か「API設定」で発行できます。Claudeに「Notionで読み取り用のAPIキーを発行する手順教えて」と聞けば、詳しく教えてくれます。

Q. 全部自分で設定しないとダメ?

A. 基本は自分で設定(APIキー取得→設定ファイル記入→動作確認)。でも、Claudeが全工程を案内してくれるので、実質的には「Claudeに聞きながらやる」だけ。

Q. 接続を切りたい時は?

A. claude mcp remove notion のように、接続名を指定して外せます。「Notion接続を切って」とClaudeに頼めば、コマンドまで自動で実行してくれます。

Q. 無料でやれる範囲は?

A. 多くのサービスは無料枠があります(GitHub、Notion等)。ただし大量に使うなら有料プランも検討。

11. やってみよう

  1. 自分が週3回以上使うツールを1つ選ぶ(Notion/GitHub/Gmail等)
  2. Claude Codeに「そのツールとつなぐ手順を教えて」と聞く
  3. ガイドに沿って接続設定
  4. 接続後、試しに1つデータを取得してみる
  5. 問題なければ、日常業務に組み込む
MCPによる外部接続は、Claude Codeを「単なるパソコンツール」から「仕事全体のハブ」に変えます。 ここまで来ると、「Claudeなしで仕事できない」ってなる人が多いです。
