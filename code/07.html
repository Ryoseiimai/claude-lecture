CODE 07

Obsidianとつなぐ
（MCP連携）

所要時間：約15分 レベル：応用
この回のゴール
  • MCPとは何かを、比喩でわかる
  • ClaudeとObsidianをつないで、ノートを読み書きできる
  • 他にどんなツールとつなげるかを知る

1. MCPって何？　「コンセント」で考える

MCP（Model Context Protocol）というのは、Claudeが外のアプリと話すための「コンセント」です。

電化製品はコンセントに差し込めば動きますよね。 形が合ってさえいれば、どんな製品でも電気が使える。 MCPはそれと同じです。

MCP = Claudeがいろんなアプリに「差し込める」コンセント。
差し込んだアプリのデータを、Claudeが読んだり書いたりできるようになる。

コンセントが無いと、Claude Codeはパソコンの中にあるファイルしか触れません。 MCPをつなぐと、ObsidianのノートもGmailも、Claudeが直接操作できるようになります。

2. ObsidianにClaudeをつなぐとどうなるか

Obsidianは「ノートをたくさん書き溜めるアプリ」です。 MCPでつなぐと、Claude Codeがそのノートを全部読めるようになります。

できるようになること

  • 「昨日のメモをまとめて」と言ったら、Obsidianのノートを探してまとめてくれる
  • 「このキーワードが出てくるノートを全部見せて」で横断検索できる
  • 「今日の日記を書いておいて」でノートを自動作成できる
  • 「バラバラなメモを整理してフォルダに分けて」が一発でできる

自分の脳みそ（Obsidian）とClaude、両方の力を合わせる感じです。

3. つなぐ手順（3ステップ）

  1. MCPサーバーの設定ファイルを用意する
  2. Claude Codeの設定にそのサーバーを追加する
  3. 「このObsidianフォルダを読んで」で動作確認する

ステップ1：設定ファイルの中身（例）

{
  "mcpServers": {
    "obsidian": {
      "command": "npx",
      "args": ["-y", "mcp-obsidian"],
      "env": {
        "VAULT_PATH": "C:/Users/yourname/Documents/MyVault"
      }
    }
  }
}

VAULT_PATH の部分を、自分のObsidianのフォルダのパスに変えます。 「パスって何」という人はClaudeに「ObsidianのVaultフォルダのパスを調べて」と聞けば教えてくれます。

ステップ2：Claude Codeに追加する

この設定ファイルをClaude Codeに追加する手順を教えて。
Obsidianと連携させたい。

Claudeがステップバイステップで案内してくれます。

ステップ3：動作確認

ObsidianのVaultにある「日記」フォルダを読んで、
最近書いたノートのタイトルを10件見せて。

これで一覧が出れば、つながっています。

うまくいかないときは「MCPの接続でエラーが出てる。設定ファイルを確認して」とClaudeに伝えてください。 設定ファイルの書き間違いが多いので、Claudeが見つけてくれます。

4. Obsidian以外にもつなげるもの

MCPに対応したツールは、どんどん増えています。 代表的なものをまとめました。

  • Gmail：メールを読む、返信を下書きする
  • Googleドライブ：ドキュメントやスプレッドシートを操作する
  • Slack：チャンネルのメッセージを読む、投稿する
  • Notion：ページを読む、新しいページを作る
  • GitHub：コードを読む、Issueを見る

全部をつなぐ必要はありません。 「これがClaudeと連携したら楽になる」と思うものから、一つずつ試してみましょう。

5. セキュリティの注意点

MCPをつなぐと、Claudeがそのアプリのデータにアクセスできるようとなります。 以下の点に注意してください。
  • APIキーは人に見せない：設定ファイルにAPIキーを書いたら、そのファイルを他人に共有しない
  • アクセス権限を絞る：「読み取りだけ」で十分なものに書き込み権限は与えない
  • 何がつながってるか把握する：つなぎすぎると管理が大変になる。必要なものだけに絞る

心配なときはClaudeに「今どのMCPがつながってるか確認して」と聞けば一覧で教えてくれます。

この回のまとめ
  • MCP = Claudeが外のアプリと話すための「コンセント」
  • Obsidianにつなぐと、ノートの読み書き・整理・検索ができる
  • 設定ファイルを用意してClaude Codeに追加するだけ
  • Gmail・Slack・Notion・GitHubなど、対応ツールは増え続けている
  • APIキーの管理と、アクセス権限の絞り込みを忘れずに
