CODE 05

Excelで1時間かかる集計が、
3分で終わった

所要時間：約15分 レベル：基本
この回のゴール
  • CSVやデータファイルをClaudeに渡して、集計・分析ができる
  • 「売上の多い順に並べて」「月別に集計して」を言葉で指示できる
  • 結果をCSVで保存したり、グラフとして見えるようにできる

1. Claudeにデータを渡す、たったこれだけ

やり方はシンプルです。CSVファイルをフォルダに置いて、そのフォルダでClaude Codeを開く。 あとは「このファイルを分析して」と言うだけ。

Claudeはファイルを開いて読んで、中身を理解します。 「こういう列があって、こういうデータが入ってますね」と確認してくれた後、 指示を待ちます。 

sales_2024.csv を開いて、どんなデータが入ってるか教えて

まずこれで「どんなデータか」を把握してもらいます。 その後、やりたいことを伝えればOK。

2. よく使う指示のパターン

並び替え

売上の多い順に並べて、上位10件だけ見せて

集計

月別に売上を合計して、一覧にして

フィルター

「区分」列が「法人」のものだけ抜き出して

比較

今年と去年の同じ月を比べて、増減を出して

Excelで手作業でやると、1時間かかることが多いです。 Claudeなら「言葉で言うだけ」で、3分もかかりません。

3. 結果を新しいファイルに保存する

集計結果を「また見たい」「誰かに渡したい」とき、保存を頼めます。 

この集計結果を「月別売上まとめ.csv」として保存して

Claudeが同じフォルダに新しいCSVを作ってくれます。 元のファイルはそのまま。上書きしません。

保存先を指定したいときは「デスクトップのreportsフォルダに保存して」のように場所も伝えれば大丈夫です。

4. グラフも作れる

数字だけじゃなく、グラフで見たいときは「グラフも作って」の一言でOK。 ClaudeはHTMLファイルを作って、ブラウザで見られるグラフを出力してくれます。 

月別の売上をグラフにして、HTMLファイルで保存して

できたHTMLファイルをダブルクリックするとブラウザが開いて、棒グラフや折れ線グラフが表示されます。 PowerPointに貼り付けることもできます。

実際に頼んだ例

sales_2024.csv の月別売上を折れ線グラフにして。
見出しは「2024年 月別売上推移」にして。
HTMLファイルで保存して。

5. ExcelとClaudeの使い分け

どちらかが「絶対正解」というわけじゃないです。得意なことが違います。

場面 向いてる方法
毎月同じフォーマットで集計する Excel（テンプレートが速い）
イレギュラーな集計・一回だけの分析 Claude
「あの条件で絞り込んで」と毎回変わる Claude
グラフを素早く作って共有したい Claude
Claudeが出した計算結果は、必ず数件だけ手で確認してください。 大量データの処理は速いですが、スポットチェックは人間がやる習慣をつけましょう。

6. 使える場面の例

  • 売上集計：商品別・担当者別・月別に集計して比較
  • アンケート分析：回答を集計して傾向を出す
  • 在庫チェック：数量が一定以下の商品だけ抜き出す
  • 経費管理：カテゴリ別に合計して予算と比較
  • 顧客リスト整理：重複を探す、条件で絞り込む
この回のまとめ
  • CSVをフォルダに置いて「分析して」と言うだけで始まる
  • 並び替え・集計・フィルターを言葉で指示できる
  • 結果を新しいCSVで保存できる
  • 「グラフも作って」でHTMLファイルに可視化できる
  • 計算結果は必ずスポットチェックする習慣を
