CODE 04

エラーが出たら
直してもらう

所要時間:約30分 レベル:実作業 必要なもの:Claude Codeインストール済み
この回のゴール
  • エラーが出てもパニックにならない
  • エラーメッセージをClaudeに渡して原因を見つけられる
  • 直った後に「なぜそうなったか」も理解できるようになる

1. エラーは「悪」じゃない、「ヒント」

パソコン作業でエラーが出ると、初心者はビビります。 真っ赤な英語メッセージが並んで、「何やねん…」と。

でも、エラーは「ここが問題だよ」と教えてくれるメッセージです。 Claudeに渡せば、だいたい解決します。

エラーは「怒られてる」じゃなくて「案内されてる」。 ここを勘違いしてる人が多いので、今日で認識を変えましょう。

2. 基本の流れ:エラー → Claudeに丸投げ

ステップ1:エラー内容をコピー

ターミナルや画面に出たエラーメッセージを全部コピー。 一部だけじゃなく、全部コピーするのがコツ。

ステップ2:Claudeに貼って聞く

以下のエラーが出た。原因と直し方を教えて。

----
[エラーメッセージをここに貼る]

ステップ3:提案された修正を適用

Claudeが「この行をこう直せばOK」と教えてくれる。 提案通り直せば、大抵直ります。

3. Claude Codeなら「丸投げ」できる

Claude Codeは、エラーを見てコードまで自動で直せるのが強み。 

script.py を実行したらエラーが出る。
原因を調べて、直してほしい。
バックアップは取ってから作業して。

流れはこうなります。

  1. Claudeが script.py を実行
  2. 出たエラーを読む
  3. 原因を特定
  4. 修正案を提示(確認付き)
  5. OK出したら修正
  6. 再度実行して、直ったか確認

これ全部、話しかけただけで進む。

4. よく出るエラーの種類と見分け方

タイプ1:ファイルが見つからない

Error: File not found: /Users/me/report.txt

→ ファイル名のタイプミス、またはファイルがそこに無い。

タイプ2:書き方の間違い(構文エラー)

SyntaxError: unexpected token ')'

→ プログラムの書き方が間違ってる。カッコの閉じ忘れとか。

タイプ3:権限がない

Permission denied

→ そのファイル・フォルダにアクセスする権限がない。

タイプ4:通信エラー

Connection timeout

→ ネット接続の問題、または相手のサーバーが落ちてる。

タイプ5:ライブラリ(部品)が無い

ModuleNotFoundError: No module named 'pandas'

→ 必要な部品ソフトが入ってない。インストール必要。

どのタイプか分かれば、対処法もだいたい見えます。 Claudeに聞けば、タイプを判別して直してくれます。

5. エラー調査の頼み方テンプレ

以下のエラーについて、次の形で回答して。

1. エラーの意味(1〜2行で)
2. 原因として考えられること(可能性の高い順に3つ)
3. 直し方(Step by Step)
4. 今後同じエラーを防ぐコツ

----
[エラーメッセージ]

この型で聞くと、理由まで理解できるので、同じミスを繰り返しません。

6. Claudeも困る時の対処

たまにClaudeも、一発で直せない時があります。そんな時はこんな風に聞き直す。

アプローチ1:情報を追加する

さっきの直し方だとこういうエラーが新しく出た。
[新しいエラー]

環境情報も載せる:
- OS: macOS 14
- Python: 3.11
- ◯◯のバージョン: 2.0

アプローチ2:ネット検索を頼む

このエラー、自分だけの問題じゃないかも。
ネットで同じエラーの事例を調べて、解決例を教えて。

Claude Codeはネット検索もできるので、最新のエラー情報を探してくれます。

アプローチ3:別角度で調べる

いったん修正やめて。

このエラーが出る前と後で、何が変わったか。
直近で私がいじったファイルは何か。

時系列で整理してから、もう一度原因を考えて。

7. ログ(履歴)から調査する

プログラムが動いた時に残る「ログ(履歴)」を見ると、エラーの謎が解けることがあります。 

logs/ フォルダにあるログファイルを全部見て、
エラー発生の1時間前から、何が起きてたか時系列で教えて。

大量のログでも、Claudeが必要な情報だけ抜き出してくれます。

8. 実例:ホームページ直しのエラー対応

想定:自分で作ったホームページに手を入れたら、レイアウトが崩れた。

さっきindex.htmlを編集したら、画面の真ん中がズレた。

- 症状:文字が右に寄って、画像が消えた
- 最後にいじったのは、index.htmlの30行目あたりのCSS

何が起きてるか調べて、直して。
直す前に何がおかしいか先に説明して。

Claudeが:

  1. index.htmlを開いて該当箇所を見る
  2. CSSの書き方を確認
  3. 何が悪いか説明
  4. 直し方を提案
  5. OK出したら修正

9. やってみよう

実際のエラーが無いと練習しづらいので、わざとエラーを起こして直す練習をしましょう。

  1. 練習フォルダに、test.py というファイルを作る
  2. 中身に print("こんにちは" と書く(カッコ閉じ忘れ)
  3. ターミナルで python test.py を実行 → エラーが出る
  4. エラーをコピーしてClaudeに渡す
  5. 直してもらう
  6. 直った後に「なぜそうなったか」も説明してもらう
エラー対応は、使えば使うほど上手くなります。 「エラー出た!ラッキー、勉強のチャンス」くらいの気持ちで向き合いましょう。
この回のまとめ
  • エラーは敵じゃない。「ヒント」
  • エラーメッセージは全文コピーしてClaudeに渡す
  • Claude Codeは、エラーを見て自動で直すところまでできる
  • 「原因・直し方・再発防止」まで聞くと理解が深まる
  • ネット検索・ログ調査も頼める
