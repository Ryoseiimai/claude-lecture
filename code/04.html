CODE 04

「全部のファイルに日付を足して」を
一発でやってくれた

所要時間：約15分 レベル：基本
この回のゴール
  • 複数ファイルへの一括変更をClaudeに任せられる
  • 大量作業を安全に進める手順（計画確認・テスト実行・元に戻す）が身につく

1. 1個ずつやる作業をまとめて丸投げ

フォルダの中にファイルが30個ある。全部のファイル名の先頭に「2024年04月_」を付け加えたい。手でやると30回リネーム作業が発生します。

Claude Code ならこの一言で終わります。

このフォルダの全ファイルの名前の先頭に、今日の日付（YYYY-MM-DD形式）をつけて

Claudeが全ファイルを確認して、一括でリネームします。30分かかっていた作業が数十秒で終わります。

2. 変更前に「まず計画を見せて」

一括変更は便利ですが、間違えると大量のファイルが壊れます。だから必ず計画を先に見ます。 

このフォルダの全ファイルの名前に日付をつけたい。
まず何をどう変えるか計画を見せて。OK出してから実行して。

Claudeが「ファイルA.txt → 2024-04-27_ファイルA.txt のように変えます」という一覧を出してくれます。それを確認してからOKを出す。この一手間が大切です。

一括変更の前は必ず「計画を見せて」を入れましょう。これだけで大きなミスのほとんどを防げます。

3. 失敗しても「元に戻して」で修正

もし実行した結果が思っていたのと違ったら、その場で言えば戻してくれます。 

さっきのリネーム、元に戻して

Claudeが変更前の状態に復元してくれます。ただし、会話を閉じてしまうと戻せないことがあります。そのため、大きな変更の前には次のセクションで説明する「バックアップ」が重要です。

4. より安全に進める：Git（バージョン管理）

「Git（ギット）」というのは、ファイルの変更履歴を記録しておく仕組みです。プログラマーがよく使いますが、普通のファイル整理でも役立ちます。

大量のファイルを変更する前に、Claudeにこう頼みます。

まずこのフォルダでgit initして、今の状態を保存して。
それから全ファイルのリネームをやって。

Claudeが Git を設定して「今の状態を記録」してから変更を進めます。何かおかしくなったら「git で戻して」と言えば変更前の状態に戻せます。

Git は少し難しい道具です。まずは「バックアップ用のフォルダにコピーしてから作業して」とClaudeに頼む方法でも十分安全です。

5. 大量ファイルは「まず3つだけ試して」

100個のファイルに一括変更をかける前に、まず少数でテストします。 

このフォルダのファイルに日付をつけたい。
まず3つだけ試してみて。問題なければ残り全部やって。

3つで結果を確認して、思い通りの動きだったら全体に展開する。これが一番安全な進め方です。

6. こんな一括作業ができる

ファイル名の一括変更

このフォルダの全ファイル名に、今日の日付を先頭につけて

テキストの一括置換

このフォルダの全テキストファイルの中で「株式会社ABC」という文字を
「ABC合同会社」に全部置き換えて

CSVの結合

このフォルダにある全CSVファイルを1つに結合して、まとめ.csvとして保存して

7. 試してみよう

  1. テスト用フォルダを作って、テキストファイルを5個入れる（中身は適当でOK）
  2. Claude Code を起動して、そのフォルダに移動する
  3. 「全ファイルに日付をつけたい。まず3つだけ試して」と頼む
  4. 結果を確認して、問題なければ「残り全部もやって」と続ける
この回のまとめ
  • 複数ファイルへの一括変更は「一言」で頼める
  • 実行前に「計画を見せて」で確認する習慣が大切
  • 失敗しても「元に戻して」で修正できる（会話中のみ）
  • 大量ファイルは「まず3つだけ試して」でテストしてから全体に適用
  • Git を使うとさらに安全（難しければバックアップフォルダを作るだけでも十分）
