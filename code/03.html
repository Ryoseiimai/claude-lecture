CODE 03

「議事録のテンプレート作って」で
保存まで終わった

所要時間：約15分 レベル：超入門
この回のゴール
  • Claudeにファイルを作らせて保存させられる
  • 実行前に「何をやるか確認する」習慣が身につく

1. 「ファイルを作って」の基本形

Claude Code でファイルを作らせるのはとてもシンプルです。「〇〇というファイルを作って」と言うだけ。 

議事録テンプレートのテキストファイルを作って、デスクトップに保存して

Claudeが内容を考えて、ファイルを作り、保存まで完了します。Coworkで「議事録テンプレートを作って」と頼んだとき、自分でコピーして保存する手間がゼロになります。

2. 作れるファイルの種類

テキストファイル（.txt）

「日報テンプレート.txt」を作って。
項目は「今日やったこと」「明日やること」「困ったこと」の3つ。

CSVファイル（.csv）

お客様リスト用のCSVファイルを作って。
列は「会社名」「担当者名」「電話番号」「最終連絡日」の4つ。
サンプルデータを3行入れておいて。

HTMLファイル（.html）

自己紹介のシンプルなホームページを作って。
名前は「田中太郎」、仕事は「営業マン」で。
index.htmlという名前でデスクトップに保存して。
保存場所を日本語で「デスクトップに」「書類フォルダに」のように指定できます。具体的なパスを書く必要はありません。Claudeが適切な場所に変換してくれます。

3. 作ったファイルを確認する流れ

ファイルを作ったあとは、すぐ開いて確認しましょう。

  1. Claudeが「作りました」と報告する
  2. デスクトップや指定した場所にファイルができているか確認
  3. ファイルをダブルクリックして中身を確認
  4. 直したい部分があれば「ここを直して」と話しかける

もし中身が思ったのと違っても、「3番目の項目を『連絡事項』に変えて」のように、追加で指示すれば修正してくれます。

4. 安全策：実行前に「何をやるか見せて」

大事なのはこの習慣です。Claudeに何かをさせる前に、まず計画を見せてもらう。 

議事録テンプレートのテキストファイルを作りたい。
まず、どんな内容で、どこに保存するか教えて。
OK出してから実行して。

Claudeが「こういう内容で、デスクトップに保存します」と説明してくれます。それを確認してから「OK、やって」と答えれば実行されます。

ファイルを上書きする場合は特に注意。「上書きしますか？」の確認が出たら、本当にそれでいいか一度止まって考えましょう。取り消しがきかない場合もあります。

5. 実際の使用例

議事録テンプレート

毎週の定例会議で使う議事録テンプレートをWordファイルで作って。
項目：日時、参加者、議題、決定事項、次回アクション。
デスクトップに「議事録テンプレート.txt」として保存して。

日報フォーマット

毎日書く日報のテンプレートを作って。
今日の実績・明日の予定・困ったことの3セクション。
シンプルなテキストファイルでいい。

お客様リストCSV

営業で使うお客様リストのCSVを作って。
会社名・担当者・電話・メール・最終訪問日の列を用意して。
サンプル行を2つ入れておいて。

6. 試してみよう

  1. Claude Code を起動する
  2. 「まず計画を見せて、OK出してから実行して」を最初に追加して指示する
  3. 「議事録テンプレートのテキストファイルをデスクトップに作って」と頼む
  4. Claudeが計画を見せてきたら内容を確認してOKを出す
  5. デスクトップにファイルができているか確認する
この回のまとめ
  • 「〇〇というファイルを作って、デスクトップに保存して」の一言で完結する
  • テキスト・CSV・HTMLなど種類を選んで作れる
  • 作ったあとはファイルを開いて中身を確認する
  • 「まず計画を見せて」と言ってから実行させるのが安全
