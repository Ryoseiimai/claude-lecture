CODE 01

黒い画面に「hello」と打ったら、
Claudeが返事した

所要時間：約15分 レベル：超入門
この回のゴール
  • Claude Codeをインストールして最初の会話ができる
  • Cowork（ブラウザ版）との違いが言葉で説明できる

1. Claude Codeって何が違うの？

Claudeには2種類の使い方があります。ブラウザで開くCoworkと、パソコンにインストールするClaude Codeです。

一言で言うと——

  • Cowork：Claudeに「答えをもらう」。チャット感覚で質問するやつ
  • Claude Code：Claudeに「やってもらう」。ファイルをその場で作ったり、変えたりする

たとえばCoworkで「議事録のテンプレートを作って」と頼むと、Claude がテキストを返してくれます。それをコピーしてどこかに貼る作業は自分でやります。
Claude Codeで同じことを頼むと、Claudeが「議事録テンプレート.txt」というファイルを作って、デスクトップに保存まで完了させてくれます。

プログラマーじゃなくても使えます。ファイルの整理・書類の自動作成・データのまとめなど、事務仕事にもじゅうぶん役立ちます。

2. インストール手順（5ステップ）

Claude Code を使うには「ターミナル」という黒い画面を使います。見た目はちょっとびっくりしますが、やることはシンプルです。

  1. Node.js をインストールする
    nodejs.org を開いて「LTS版」をダウンロード→インストール。これは Claude Code を動かすための土台です。
  2. ターミナルを開く
    Windows なら「スタートメニュー」→「PowerShell」または「コマンドプロンプト」。 Mac なら「Launchpad」→「ターミナル」を検索。
  3. インストールコマンドを打つ
    黒い画面に下のコマンドをコピペして Enter を押す。 
    npm install -g @anthropic-ai/claude-code
    しばらくすると「インストール完了」の表示が出ます。
  4. 作業フォルダを作って移動する
    どこでも好きな場所にフォルダを作って、ターミナルでそこに移動します。 
    cd C:\Users\自分の名前\Desktop\claude-test
    （Macなら cd ~/Desktop/claude-test）
  5. 起動してログイン
    claude
    と打つと起動します。初回はブラウザが開いてClaudeアカウントへのログインを求められます。ログインすれば会話開始。
手順3で npm: command not found と出た場合、Node.js のインストールがまだです。手順1からやり直してください。インストール後はターミナルを一度閉じて開き直すと直ることが多いです。

3. 最初に打ってみる言葉

起動できたら、まずこれを打ってみましょう。 

こんにちは、何ができるか教えて

Claudeが返事をします。Coworkと同じ感覚で話しかけてOKです。

次に、こっちも試してみてください。 

今いるフォルダに何が入っているか教えて

Claudeがパソコンのフォルダをのぞいて、中身を一覧にしてくれます。これがCoworkとの最大の違い——自分のパソコンの中を直接見てくれているのです。

4. 画面の見方

Claude Code の画面はシンプルです。流れを覚えれば迷いません。

  1. 指示を打つ：自分がやってほしいことを日本語で書く
  2. 確認が出る：「このファイルを書き換えていいですか？」など。y で OK、n で断れる
  3. 実行される：Claudeが作業を進める。ツール使用の表示が出る
  4. 結果が届く：完了したらClaudeが報告してくれる
最初のうちは確認が出るたびに読んで、内容を理解してから y を押す習慣をつけましょう。何をされているかがだんだんわかってきます。

5. よくあるつまずきと対処

「npm が見つからない」と出る
Node.js が入っていません。nodejs.org でインストールして、ターミナルを開き直してください。

「権限がない」というエラーが出る（Mac）
コマンドの先頭に sudo をつけて実行してみてください。パスワードを聞かれたらパソコンのログインパスワードを入力します。

文字化けする
Windows のコマンドプロンプトより PowerShell か Windows Terminal を使うと文字化けしにくいです。
