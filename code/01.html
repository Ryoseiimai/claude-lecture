CODE 01

Claude Codeって何?
入れてみる

所要時間:約30分 レベル:導入 必要なもの:パソコン(Mac/Windows/Linux)+Claudeアカウント
この回のゴール
  • Claude Codeが何者か、アプリ版と何が違うのかが分かる
  • 自分のパソコンにClaude Codeをインストールできる
  • 起動して、最初の「Hello」を打てる

1. Claude Codeって何?

Claude Code(クロードコード)は、自分のパソコンに直接インストールして使うClaudeです。 アプリ版(claude.ai)はブラウザで動きますが、Claude Codeはパソコン上のツールとして動きます。

アプリ版と何が違う?

一番の違いは——「自分のパソコンのファイルを直接いじれる」こと。

  • アプリ版:ブラウザの中で会話するだけ。ファイルは渡して読んでもらう
  • Claude Code:パソコンのファイル・フォルダを直接読み書き・編集できる

イメージは、「自分のパソコンに、優秀な助手が住み着いた」感じ。 「このフォルダの中の写真を全部整理して」「この報告書を修正して」と頼めば、その場で実行してくれます。

プログラマーじゃないけど、使える?

使えます。もともとはプログラマー向けに作られましたが、やれることはコードの世界に限りません。

  • 大量のExcelファイルの集計・整理
  • PDFや画像のフォルダ単位での処理
  • 毎日の定型作業の自動化
  • ホームページの修正
  • もちろん、プログラムも書ける

事務作業がメインの人でも、十分使う価値があります。

2. 何ができるの?(例)

事務系

  • 「このフォルダのPDF100枚、全部表にまとめて」
  • 「Excelファイル10個分のデータを統合して、1つのファイルにして」
  • 「フォルダ名を、日付+案件名の形式に全部リネームして」
  • 「同じ内容のメールを、宛先リストにある30人に送信(下書き保存)」

制作系

  • 「このホームページの見た目を、もう少しスッキリした感じに直して」
  • 「写真をまとめたスライドショー(HTML)を作って」
  • 「ブログ記事の画像を、全部Webに最適なサイズに変換して」

開発系

  • 「バグを直して」「テストを書いて」「ドキュメント作って」
  • 完全なプログラマー作業まで全部こなせる

自動化系

  • 「毎朝9時にニュースを集めて、メールで送る仕組みを作って」
  • 「定期的にホームページのバックアップを取る」

3. インストールする前の準備

インストールには、いくつか準備がいります。

必要なもの

  • パソコン:Mac/Windows/Linux、どれでもOK
  • インターネット接続:常時使う
  • Claudeアカウント:LESSON 01(アプリ編)で作ったやつ
  • Claude Pro以上の有料プラン:無料でも試せるが、本格利用なら推奨

パソコンのスペック

重たいソフトじゃないので、普通のパソコンでOK。

  • メモリ:8GBあれば快適(4GBでも動く)
  • ストレージ:数百MB空きがあれば十分

4. インストール手順(Mac/Windows/Linux共通)

Claude Codeは「ターミナル」や「コマンドプロンプト」と呼ばれる、黒い画面のツールにインストールします。 ちょっとビビる見た目ですが、やることは簡単です。

手順1:ターミナルを開く

  • Mac:Launchpad → 「ターミナル」で検索
  • Windows:スタートメニュー → 「PowerShell」または「ターミナル」
  • Linux:Ctrl+Alt+T
スクリーンショット:MacのターミナルとWindowsのPowerShellの起動画面

手順2:インストールする(2つの方法から選ぶ)

方法は2つ。自分が楽なほうでOK。パソコン慣れてない人は「方法A」が無難。

方法A:公式サイトからインストーラーをダウンロード(おすすめ)

ブラウザで claude.com/claude-code を開いて、 自分のOS(Mac/Windows)のインストーラーをダウンロード → ダブルクリックで入れる。 普通のアプリのインストールと同じ感覚です。

方法B:コマンドで一発

ターミナルに、次の1行をコピペして、Enter。

npm install -g @anthropic-ai/claude-code
方法BにはNode.js(ノードジェイエス)というソフトが必要です。 もし「npm not found」と出たら、それが入ってないサイン。 nodejs.org から「LTS版(長く使える安定版)」をダウンロードしてインストール。 その後、ターミナルを一度閉じて開き直し、上のコマンドを再度実行。 よく分からなくなったら、方法Aに切り替えて大丈夫。

手順3:起動する

claude

これでClaude Codeが立ち上がります。

手順4:ログインする

初回起動時、ログインを求められます。 画面の案内にしたがって、ブラウザが立ち上がったら、自分のClaudeアカウントでログイン。

準備完了。自分のパソコンで、Claude Codeが動き始めた状態です。

5. はじめての会話

ターミナルに、こう打って送信してみてください。 

こんにちは。自己紹介して。
今いるフォルダに何があるか教えて。

Claudeがパソコンのフォルダを覗いて、中身を教えてくれます。 アプリ版との違いを、ここで初めて体感します。

スクリーンショット:ターミナル画面でClaudeが自己紹介してフォルダ内容を返している様子

6. 最初につまずきやすいポイント

つまずき1:「どこで動いてるか」が分からない

Claude Codeは、「ターミナルを開いた時点の場所(フォルダ)」で動きます。 例えばデスクトップのフォルダで動かしたければ: 

cd ~/Desktop/myproject
claude

これで、そのフォルダの中で作業してくれます。

つまずき2:「許可を求められた」

Claudeがファイルを書き換えようとすると、「これやっていい?」と聞いてくることがあります。 一つずつ確認して、OKなら「yes」と返事する。 慣れるまでは、一回一回確認する設定で使うのがおすすめ。

つまずき3:変なことを言ってる

アプリ版と同じで、たまに間違えます。 特にファイル操作系のミスは影響が大きいので、 バックアップを取ってから大きな作業を頼むのが鉄則。

大事なファイルは、Claude Codeに頼む前に別の場所にコピーを取る。 「フォルダのファイル名全部変えて」で、やり直せない書き換えをされるのが最悪のパターン。

7. 終了のしかた

Claude Codeを閉じるには、ターミナルで: 

/exit

もしくは、Ctrl+D、Ctrl+C で抜けられます。 会話の履歴は保存されていて、次回起動時に続きから始められます。

8. 料金について

料金は、基本的にアプリ版と共通の枠です。

  • Claude Code自体は無料でインストールできる
  • 動作には、Claudeアカウントが必要
  • 無料プランでもちょっとは使えるが、ヘビーに使うならPro(月約3,000円)推奨
  • たくさん使う人向けにはMaxという上位プランもあり(月15,000円か月30,000円の2段階、為替で多少変動)

9. やってみよう

  1. ターミナル/PowerShellを開いてclaude起動まで進める
  2. 「こんにちは」と打って、返事をもらう
  3. 「今いるフォルダの中身を一覧にして」と頼んでみる
  4. 問題なく動いたら、このLESSONはクリア
