CODE 08

ゴールだけ伝えたら、
手順から全部考えてやってくれた

所要時間：約15分 レベル：応用
この回のゴール
  • 「〇〇したい」だけ伝えて、手順を考えさせる指示ができる
  • 途中で方向が違うと気づいたら、止めて修正できる
  • Claude Code編8パターンを振り返り、全体像をつかむ

1. 「手順」を指示しない。「ゴール」だけ渡す

これまでのレッスンでは「ファイルを読んで」「集計して」「スクリプトを作って」のように、 やることをある程度指示してきました。

でも、Claude Codeに一番向いている使い方は、ゴールだけ伝えて、手順はClaudeに考えさせることです。

「どうやるか」は言わない。「どうなってほしいか」だけ言う。

ゴール指示の例

「受信」フォルダがぐちゃぐちゃになってる。
種類ごとに整理されて、どこに何があるか分かる状態にしてほしい。
どうすればいいか考えて、やって。

Claudeがまず状況を調べて、「こういう整理方法でいいですか」と提案してきます。 OKを出したら実行する、という流れです。

2. Claudeが自分で考えて動く様子

ゴールを渡すと、Claudeは自分でやることを考えます。 こんな感じで動きます。

  1. 「受信」フォルダの中身を確認する
  2. どんなファイルがあるかを分類する
  3. 「PDFは請求書フォルダ、画像は写真フォルダ、Excelは集計フォルダに分けます。いいですか？」と確認する
  4. OKが出たら実行する
  5. 完了したら「こうなりました」と報告する

何百個のファイルがあっても、自分で全部やります。 途中で「あ、このファイルはどっちに入れますか？」と確認を入れることもあります。

3. 「待って、方向が違う」で止める方法

途中で「なんか思ってたのと違う」と気づいたら、すぐ止められます。 

待って。その方向じゃない。
Excelファイルは集計用じゃなくて「元データ」フォルダに分けたい。
いったん止まって、もう一度整理方針を確認させて。

Claudeは途中で止まって、もう一度確認してから再開します。 「取り返しのつかない操作をする前に止まって確認して」と最初に伝えておくと安全です。

大量ファイルの操作は「まず移動リストだけ見せて、OKを出したら実行して」と伝えると、 実行前に確認できて安心です。

4. こんな「丸投げ」ができる

  • フォルダ整理：「このフォルダを整理して、見やすくして」
  • 段取りを組む：「この仕事の進め方を考えて、スケジュールを作って」
  • 比較分析：「3社の提案書を比べて、どれがいいか理由付きで教えて」
  • 資料作成：「この会議の内容をまとめて、次回用のアジェンダを作って」
  • システム構築：「毎月の売上レポートを自動で作る仕組みを作って」

5. Claude Code編　8パターン振り返り

LESSON 01から08まで、Claude Codeで何ができるかを一通り見てきました。

LESSON できること
01 Claude Codeを起動して話しかける
02 ファイルを作る・編集する
03 ファイルを読ませる・書かせる
04 エラーが出たら直してもらう
05 データ集計・グラフ作成
06 繰り返し作業の自動化
07 外部ツールとの連携（MCP）
08 ゴールだけ渡して丸投げ

この8パターンに加えて、アプリ編（Claude.ai）のCowork編8パターンと合わせると、 全16の使い方が身についた状態です。

6. 次のステップへ

この講座を終えた後、さらに深く使いこなしたい人向けに、3つの方向性を紹介します。

  • CLAUDE.mdを育てる：自分専用の設定ファイルをどんどん充実させていく。 使うほどClaudeが「自分をよく知ってる相棒」になっていく。
  • スラッシュコマンドを作る：よく使う指示をショートカットに登録できる。 「/日報」と打つだけで日報作成が始まる、みたいなことができるようになる。
  • 自動化を深掘りする：タスクスケジューラ + スクリプトの組み合わせを増やして、 「朝起きたら全部終わってた」という状態を作っていく。
まずは「一番面倒に思ってる作業」をClaudeに相談するところから始めましょう。 「こんな作業があるんだけど、Claudeで自動化できる？」と聞くだけでいいです。
この回のまとめ
  • 「どうやるか」じゃなく「どうなってほしいか」だけ伝えると、Claudeが全部考える
  • 途中で「待って」と言えばいつでも止まって確認してくれる
  • 大量操作は「リストを見せてからOK出して実行」が安全
