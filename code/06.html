CODE 06

ワンボタンで
呼び出す機能を作る

所要時間:約30分 レベル:応用 必要なもの:Claude Codeインストール済み
この回のゴール
  • よく使う作業を「スラッシュコマンド」で呼び出せるようにする
  • 専門家キャラ「エージェント」を作れるようになる
  • 自分だけの「ワンボタン機能集」を作れる

1. 毎回同じ指示、してない?

Claude Codeを使っていると、「毎回同じ指示してるな」と気づく瞬間があります。

  • 毎朝「今日のToDoを整理して」
  • 週末に「今週の振り返りをして」
  • コード書いた後に「レビューして」

これらをワンボタンで呼び出せるようにする仕組みが、「スラッシュコマンド」です。

/朝ルーティン と打つだけで、毎朝のToDoまとめが自動実行される。そんなイメージ。

2. スラッシュコマンドって何?

Claude Codeの会話欄で、/(スラッシュ)から始まる言葉を打つと、登録した指示が実行される仕組み。

最初から使えるコマンド

Claude Codeには、最初からいくつか便利なコマンドがあります。

  • /help - ヘルプ
  • /clear - 会話をリセット
  • /model - 使うモデルの切り替え
  • /init - CLAUDE.mdの自動生成
  • /config - 設定変更

自分で作れる

これらに加えて、自分オリジナルのコマンドを追加できます。

3. スラッシュコマンドの作り方

保存場所

  • プロジェクト限定:そのプロジェクトフォルダの中の .claude/commands/
  • 全プロジェクト共通:~/.claude/commands/ (ホーム下)

作り方(Claudeに頼む)

「朝ルーティン」というスラッシュコマンドを作って。

場所:~/.claude/commands/morning.md

内容:
- 今日の日付と曜日を教える
- 今日のカレンダー予定を確認(もし接続があれば)
- 未読メールの件数確認
- 今日やるべきことを3つ提案

日本語で、フレンドリーな口調で。

Claudeが .mdファイルを作ってくれて、次から /morning で呼び出せるようになります。

中身のフォーマット

スラッシュコマンドは、単純なMarkdownファイル。

# 朝のルーティン

以下を順番にやってください。

1. 今日の日付と曜日を教える
2. 今日やるべきことを3つ提案(優先度順に)
3. 励ましの一言

4. 使えるコマンド例10連発

日常系

  • /morning — 朝のルーティン
  • /evening — 1日の振り返り
  • /week-review — 週末の振り返り
  • /focus — 今から集中する内容を1つ決める

仕事系

  • /meeting-prep — 会議前の準備(議題・資料確認)
  • /reply-mail — メール返信の下書き作成
  • /proposal — 提案書のフォーマット出力
  • /invoice — 請求書のテンプレート生成

作業系

  • /review — コードやドキュメントの見直し
  • /backup — 今のフォルダをバックアップ(Git+コピー)

5. 「エージェント」も作れる

スラッシュコマンドは「命令」ですが、もう一歩進んだ仕組みとして「エージェント(専門家キャラ)」が作れます。

エージェントって?

特定の専門性を持ったClaudeのキャラクター、みたいなもの。 例えば:

  • 翻訳専門エージェント:とにかく翻訳だけ、フォーマットも統一
  • コードレビュー専門エージェント:コードを厳しめにチェック
  • 文章校正エージェント:誤字・文法・読みやすさを指摘
  • アイデア出しエージェント:自由な発想で量を出す

メインのClaudeとは別に、必要な時だけ呼び出せる「専門スタッフ」です。

作り方

保存場所:~/.claude/agents/名前.md

Claudeに頼んで作ります。

「校正マン」というエージェントを作って。

場所:~/.claude/agents/koseiman.md

役割:
- プロの校正者として動く
- 日本語の文章の誤字脱字・文法・言い回しをチェック
- 改善案を3パターン出す

性格:
- 厳しめだけど愛がある
- 理由を必ず添える

使い方

作ったあとは、メイン会話で自然に呼び出すだけ。「◯◯エージェントで〜」と頼めば、Claudeが自動で連れてきてくれます。

校正マンエージェントで、以下の文章をチェックして。

----
[文章を貼る]

登録済みのエージェント一覧は /agents コマンドで見られます。 ここから編集・削除もできます。

6. 組み合わせ:最強の個人アシスタント

スラッシュコマンド + エージェントを組み合わせると、自分だけの個人アシスタントができあがります。

例:ライターのAさんのセット

  • /article-plan — 記事の構成を考えるコマンド
  • /article-draft — ドラフト生成のコマンド
  • 校正マンエージェント — 最終チェック用
  • タイトルマンエージェント — キャッチーなタイトル案を出す

こうなると、記事1本作る流れが全部コマンド化できます。 

/article-plan 副業の税金対策について
# → 構成が出る

/article-draft
# → 構成を元にドラフトが出る

校正マンエージェントでドラフトをチェック
# → 修正案を出す

タイトルマンエージェントでタイトル案5つ
# → 魅力的な候補が並ぶ

7. コツ:最初は「よく使うやつ」だけ

最初から大量のコマンドを作ろうとしないこと。 週に3回以上使う作業を1〜2個選んで、まずそれだけコマンド化。

「これ、コマンドにしたほうが楽」と思ったら、そのタイミングで追加する。 気づいたら10個、20個と育っていくのが理想です。

8. やってみよう

  1. 自分の仕事で週3回以上やってる作業を1つ思い出す
  2. Claudeに「この作業をスラッシュコマンドにして」と頼む
  3. 作ったあと、実際に /コマンド名 で呼び出して試す
  4. 動きを見て、調整したければコマンドファイルを直接編集
スラッシュコマンドは、Claude Code上級者の第一歩。 ここまで来ると、「Claudeが自分の延長になった」感覚が出てきます。
この回のまとめ
  • スラッシュコマンド(/コマンド名)で、よく使う指示をワンボタン化
  • 保存場所は ~/.claude/commands/ か プロジェクト内の .claude/commands/
  • エージェント(専門家キャラ)も作れる。会話中に「◯◯エージェントで〜」と呼ぶだけ
  • 両方組み合わせれば、自分専用の個人アシスタントに
  • 最初は「週3回以上使う作業」だけコマンド化
