CODE 06

「毎日やってるこの作業、
自動化して」が通じた

所要時間：約15分 レベル：基本
この回のゴール
  • 繰り返し作業を「言葉で説明」してスクリプトにできる
  • Claudeが書いたプログラムを安全に動かせる
  • Windowsで毎日自動で動かす仕組みを作れる

1. 自動化の考え方：手でやってることを言葉にするだけ

「自動化」というと難しそうに聞こえますが、考え方はシンプルです。 「今、自分が手でやっていることを、そのままClaudeに説明する」だけ。

プログラムの知識はいりません。 「毎朝これをやってる」という作業を普通の言葉で伝えれば、 Claudeがそれをやるプログラムを書いてくれます。

プログラムを「書く」のではなく、「説明する」だけでいい。

2. 実際に頼んでみる

例：ファイルの振り分け

毎朝「受信」フォルダに新しいPDFファイルが届く。
ファイル名に「請求書」が含まれるものは「請求書」フォルダに、
「契約書」が含まれるものは「契約書」フォルダに移動させたい。

これを自動でやるプログラムを作って。

例：日報ファイルの自動作成

毎日の日報ファイルを自動で作りたい。
「YYYY-MM-DD_日報.txt」という名前で、
デスクトップの「日報」フォルダに作る。
中身は「日付」「今日やったこと」「明日やること」の見出しだけ入ってる状態で。

例：定期バックアップ

毎日夜、「仕事」フォルダ全体を
「バックアップ/YYYYMMDD」フォルダにコピーしたい。
古いバックアップは7日分だけ残して、それより古いのは自動で消して。

こういう言葉で伝えると、Claudeがプログラムを書いてくれます。

3. 動かすまでの流れ

  1. Claudeがプログラム（スクリプト）を書く
  2. 「まずテスト用フォルダで試して」と安全確認を指示する
  3. 問題なければ「本番フォルダで動かして」と指示
  4. エラーが出たら「直して」と伝えるだけ
最初に必ず「テスト用フォルダで先にやって」と伝える習慣をつけましょう。 本番のファイルに触る前に動作確認できて、安心です。

テスト指示の例

本番フォルダは触らないで。
まずデスクトップに「テスト用」フォルダを作って、
そこで動くか確認してから教えて。

4. エラーが出ても「直して」の一言

プログラムがうまく動かないとき、エラーメッセージが出ます。 そのメッセージをそのままClaudeに渡してください。 

動かしたらこんなエラーが出た。直して。

----
[エラーメッセージをここに貼る]

Claudeが原因を調べて、直したバージョンを出してくれます。 何度かやりとりすれば、だいたい動くようになります。

5. 毎日自動で動かす仕組みを作る（Windows）

「毎朝9時に自動実行したい」というときは、 Windowsの「タスクスケジューラ」という機能を使います。 設定の仕方もClaudeに聞けば教えてくれます。 

さっきのスクリプトを、毎朝9時に自動で動かしたい。
Windowsのタスクスケジューラで設定する手順を教えて。

一度設定すれば、あとは毎日自動で動き続けます。 パソコンを開くだけで、作業が終わっている状態になります。

6. こんな作業が自動化できる

  • ファイル整理：届いたファイルを種類別に振り分け
  • バックアップ：大事なフォルダを毎日自動でコピー
  • 日報作成：毎日の日報ファイルを自動で用意
  • データ変換：毎月届くExcelを決まった形に整える
  • フォルダ掃除：古いファイルを自動で削除・整理
ファイルを削除するプログラムを作るときは、「削除する前にリストだけ表示して確認させて」と先に伝えてください。 間違って大事なファイルを消してしまうのを防げます。
この回のまとめ
  • 「手でやってること」を言葉で説明するだけで自動化できる
  • Claudeがプログラムを書く → まずテスト → 確認してから本番
  • エラーが出たらそのまま渡して「直して」と言えばいい
  • Windowsタスクスケジューラで毎日自動実行できる
  • 削除系の処理は「リスト表示→確認→削除」の順で安全に
