CO-WORK 07

計算や表を
作ってもらう

所要時間:約30分 レベル:便利技 必要なもの:Claudeのアカウント
この回のゴール
  • Claudeに数字の計算・集計を任せられる
  • Excel風の表・グラフが作れる
  • Excelに戻す時の形式で出力してもらえる

1. Claudeは「数字」も得意

「AI=文章を書くもの」と思われがちですが、Claudeは数字の集計・計算も得意です。 しかも、Claudeには「分析モード」という特別な機能があり、実際に電卓として動くので、大量のデータを正確に計算できます。

何ができるの?

  • 売上データの集計(月別、担当者別、商品別)
  • Excelの関数を作ってもらう(VLOOKUP、SUMIFなど)
  • データから傾向を見つけてもらう
  • グラフ(棒・折れ線・円)を作る
  • 将来の予測(来月の売上など、ざっくり)
  • 家計簿の整理・分析
  • スケジュール表・ガントチャート

2. 基本:数字を渡して聞くだけ

一番かんたんな例

以下の売上データを見て。

1月:120万円
2月:135万円
3月:98万円
4月:145万円

- 平均・合計・最高月・最低月を計算して
- 傾向を一言で
- 5月の予測(+理由)も

これだけで、ちゃんと集計と考察を返してくれます。

Excelデータをそのまま渡す

Excelファイル(.xlsx)やCSVを、入力欄にドラッグ&ドロップするだけでOK。 「このファイルの中身を集計して」と頼めば、数百行のデータでも一気に処理してくれます。 

このCSV(2026年第1四半期の受注データ)を分析して。

- 担当者別の売上ランキング
- 商品カテゴリ別の割合(%)
- 一番伸びている商品TOP3
- 要注意な(下がっている)顧客

結果は、それぞれ表形式でお願い。

3. Excel関数を教えてもらう

Excelで「この計算、関数でできるのかな?」と思った時も、Claudeに聞けばすぐ答えが出ます。

例1:条件に合うものだけ合計したい

Excelで、A列が「東京」のB列の数値だけを合計したい。
どの関数を使えばいい?

Claudeの返事:

=SUMIF(A:A, "東京", B:B) でOKです。 A列で「東京」と一致する行のB列を合計します。

例2:別シートから探してくる

顧客IDから、別シート「顧客一覧」にある会社名を引っ張ってきたい。
やり方と関数を教えて。

「VLOOKUPなのかXLOOKUPがいいのか」(どちらも別シートを検索するExcelの関数の名前)みたいな比較つきで、初心者に向けた説明をしてくれます。

例3:エラーが出た時

Excelでこの関数を入れたら「#N/A」と出た。
=VLOOKUP(A2, 顧客一覧!A:B, 2, FALSE)
原因と直し方を教えて。

4. 表を作ってもらう

LESSON 04でも少し触れましたが、Claudeは表も直接作れます。

よくある表のパターン

  • 比較表:自社と競合、商品A・B・C、プランS・M・L
  • スケジュール表:プロジェクトの進行、週次の予定
  • 料金表:サービスの価格体系
  • チェックリスト:確認項目・実施状況
  • 名簿・顧客一覧:連絡先・属性

頼み方

以下の条件で、料金プラン表を作って。

プラン:ライト / スタンダード / プレミアム
比較項目:月額料金 / 利用可能回数 / サポート / 特典
形式:表(左端が項目、上がプラン名)

あとで、Excelに貼り付けたいので、タブ区切りでも出して。

表を作ったあと、「Excelに貼り付け用に出して」と頼めば、そのままExcelに貼り付け可能な形式で出してくれます。

5. グラフを作ってもらう

データを渡して、「グラフにして」と頼むだけで、その場でグラフを描いてくれます。

作れる主なグラフ

  • 棒グラフ(月別売上など)
  • 折れ線グラフ(推移・トレンド)
  • 円グラフ(構成比)
  • 散布図(相関関係)
  • 組み合わせ(売上+利益率など)

頼み方の例

以下のデータを、折れ線グラフにして。
タイトル:「2026年 月別売上推移」
縦軸:売上(万円)
横軸:月

1月:120 / 2月:135 / 3月:98 / 4月:145
5月:160 / 6月:175 / 7月:150 / 8月:180

グラフの下に、読み取れる傾向を3つ書いて。
スクリーンショット:Claudeが描いたグラフ + 下に傾向の分析

6. 予測・分析もしてくれる

過去のデータを渡して、「次はどうなりそう?」と聞けます。 

過去6ヶ月の売上データです。

[データ省略]

- 7月の売上を予測して(理由も)
- このままいくと、年間でいくらになりそう?
- 落ち込みそうなリスクと、防ぐアイデアを3つ
予測はあくまで過去データからの推測です。 突発的な出来事(新商品投入、競合の動き)は含まれません。 「参考値」として使って、最終判断は自分でしましょう。

7. Excelに戻すには

方法1:コピペする

表をそのままコピーして、Excelに貼り付け。 簡単な表ならこれで十分。

方法2:CSVで出力する

この表を、CSV形式(カンマ区切り)で出力して。
1行目は項目名、2行目以降がデータで。

出てきたテキストを.csvで保存すれば、Excelで開けます。

方法3:Excel関数つきで出す

この売上データを、Excel用に出してほしい。

- データ部分はそのまま貼り付け可能な形式で
- 末尾に合計行、平均行を足す。関数付きで
  (=SUM、=AVERAGE)

8. やってみよう

  1. 自分の家計(今月の支出)を10行くらいClaudeに渡して、カテゴリ別に集計してもらう
  2. 仕事のExcelファイルを1つ放り込んで、傾向を分析してもらう
  3. 「Excelでこんな関数ある?」と疑問に思ってることを、聞いてみる
Claudeは数字が得意ですが、大事な計算(給与・税金・契約金額など)は必ず最後にダブルチェックしましょう。 集計のスピードアップには最強ですが、公式書類の最終確認は自分で。
この回のまとめ
  • 数字の集計・計算は、Claudeの得意分野
  • Excelファイルを直接ドロップしても分析してくれる
  • Excel関数の相談、エラーの解決もできる
  • 表・グラフの作成、Excelに戻す形式での出力もOK
  • 予測や分析もできるが、最終判断は自分で
