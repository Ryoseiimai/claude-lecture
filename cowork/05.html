CO-WORK 05

GmailやSlackと
Claudeをつなぐ

所要時間:約30分 レベル:応用 必要なもの:Claude有料プラン + 連携したいアカウント
この回のゴール
  • Claudeを「普段使っているアプリ」とつなげる方法が分かる
  • Gmail・Slack・Googleドライブのどれか1つと接続できる
  • 「先週のメール確認して」「Slackの◯◯チャンネル要約して」ができる

1. 「連携」って何ができるようになるの?

ここまでは、Claudeに「自分で資料をコピペして渡す」必要がありました。 でも——「連携」機能を使うと、Claudeがあなたのアプリを直接見てくれます。

例えば、こういう頼み方が全部できるようになります。

  • 「先週Gmailで届いた◯◯社からのメール、全部まとめて」
  • 「Slackの#営業チャンネル、今日の動きを要約して」
  • 「Googleドライブの『提案書』フォルダから、A社向けの資料を引っ張ってきて」
  • 「カレンダーから来週の予定を見て、空いてる時間に30分のブロックを3つ入れて」

今まで「コピペ → Claudeに貼る → 頼む」だった作業が、「Claudeに直接頼む」だけで済むようになります。

イメージは、新入社員に「自分のGmail見ていいから、先週のA社のやりとり整理して」と頼む感じ。 Claudeが、あなたの手足になって動いてくれます。

2. つなげられる主なアプリ

2026年現在、つなげられる代表的なアプリは以下のとおり。

メール・カレンダー

  • Gmail(メールの読み書き)
  • Google Calendar(予定の確認・作成)
  • Microsoft Outlook(メール・予定)

ファイル・文書

  • Googleドライブ(ファイル閲覧・検索)
  • Notion(ページの読み書き)
  • OneDrive

チャット・SNS

  • Slack(チャンネル・DMの読み取り)
  • Microsoft Teams

業務ツール

  • Jira(タスク管理)
  • Linear(タスク管理)
  • Asana(プロジェクト管理)
  • HubSpot(顧客管理)
  • Salesforce(営業管理)
  • Zapier(あらゆる自動化)

増え続けているので、公式の最新リストを見るのが確実です。 たいていのメジャーな業務ツールは、すでに対応しているか、近いうちに対応します。

3. つなげる手順(Gmailの例)

事前準備

  • Claude Pro以上のプラン
  • 連携したいサービスのアカウント(この例ではGoogleアカウント)

手順

  1. Claudeにログインして、画面右上の自分のアイコン(またはプロフィール)をクリック
  2. 「Settings(設定)」を開く
  3. 左側メニューの「Connectors(コネクター)」または「Integrations(連携)」を選ぶ
  4. Gmailを探して「Connect(接続)」をクリック
  5. Googleアカウントの選択画面が出てくるので、使いたいアカウントを選択
  6. Claudeへのアクセス許可を聞かれる。内容を確認して「許可」
  7. 接続完了!
スクリーンショット:Connectors画面 + Gmailを接続するボタン

接続後、どう使う?

普通のチャット欄で、話しかけるだけ。

例えば:

先週届いたメールの中で、取引先からの返信を時系列で一覧にして。
相手の名前、件名、内容の要点、未返信かどうか、を表で。

Claudeが裏でGmailを見て、まとめてくれます。 最初の1回目は確認ダイアログが出ることがあります(「本当に送信していい?」など)。

4. Slackの接続例

手順はGmailとほぼ同じ。

  1. 設定 → Connectors
  2. Slackを選択 → Connect
  3. 自分のSlackワークスペースを選んで許可
  4. 完了

使い方の例:

  • 「#営業チャンネルの今週の議論を要約して」
  • 「田中さんからの最近10件のDM、内容を整理して」
  • 「#全体連絡の今月の告知を、時系列にまとめて」

5. できること・できないこと

できること

  • メール・チャンネル・ファイルの読み取り・検索
  • メールの下書きまで作成(送信は確認付き)
  • カレンダーに予定を追加(確認付き)
  • Slackにメッセージ投稿(確認付き)
  • NotionやGoogle Docsのページ作成

できないこと・注意点

  • 連携していないアカウントの中身は見られない
  • アプリ側で権限を絞っている場合、そこまでしか見えない
  • 機密メッセージなど、読めない部分もある
  • 実行するたびに、Claudeの利用枠を消費する

6. セキュリティの話(重要)

Claudeに連携するということは、そのアカウントの中身をClaudeが読めるようになるということです。 会社のアカウントをつなぐ時は、必ず会社の規定・上司に確認してください。

覚えておきたいこと

  • 個人のGmailと、会社のGmailは別のアカウント。誤接続に注意
  • 連携はいつでも解除できる(Connectors画面の「Disconnect」)
  • 解除すると、Claudeは以後そのアカウントを見られなくなる
  • 社外の人(クライアントなど)のメールを扱う時は、特に慎重に
  • 一度Claudeが読んだ内容は、会話履歴として残る(消したいなら履歴削除)

おすすめの使い方

  • まずは個人の・影響の少ないアカウントで試す
  • 慣れてから仕事用アカウントに広げる
  • 使わない連携は切っておく
  • 迷ったら、「この内容、人に見られても大丈夫か?」で判断

7. 連携を使った仕事術の例

朝のルーティン

おはよう。今日の仕事を整理したい。

1. Gmailで今日の未読メールの中から、返信必要なものを抽出
2. Slackの自分宛てのメンションを、内容と緊急度で整理
3. カレンダーで今日の予定を時系列で
4. 上記を踏まえて、今日の優先タスク3つを提案

これをまとめて出して。

週次レビュー

今週のふりかえりをしたい。

- Gmailで送信した先を一覧
- Slackでアクティブだったチャンネル
- カレンダーで実施した会議の件数と時間
- 来週に持ち越すタスク

1枚の振り返りメモにして。

クライアント対応

A社(メールドメイン:@a-company.com)との過去3ヶ月のやりとりを見て、
現在進行中の案件と、保留中の案件、それぞれの最終更新日を表にまとめて。

8. やってみよう

まずはGmailの連携から始めるのがおすすめ。

  1. 個人のGmailアカウントを1つ、Claudeに接続してみる
  2. 「先週の受信メールを差出人別に一覧にして」と頼む
  3. 返ってきた内容が正しいか、念のためGmailを直接見て確認
  4. 違和感なければ、仕事用アカウントに広げていく
最初はビビるかもしれませんが、実際に動くと感動します。 「コピペする手間」が消えるだけで、毎日30分くらい浮くはず。
