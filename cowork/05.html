COWORK 05

バラバラな情報を
表に整理させる

所要時間：約15分 レベル：基本
この回のゴール
  • 文章やメモから比較表・リスト・カテゴリ分けを作れる
  • 「表にして」と「項目別に整理して」の使い分けができる
  • 作った表をNotionやGoogle Docsにそのまま貼り付けられる

1. 「表にして」vs「項目別に整理して」

情報を整理するとき、Claudeに渡す言葉で出来上がりが変わります。 「表にして」は横に並べて比べたいとき、 「項目別に整理して」は分類してまとめたいときに使います。

使い分けのイメージ

  • 表にして → ツールAとBとCを横に並べて比べる
  • 項目別に整理して → 会議メモを「決定事項・宿題・保留」に分ける
  • 箇条書きにして → 長い文章の要点だけ抜き出す
  • カテゴリ分けして → バラバラな商品を種類ごとにまとめる
迷ったら「整理して」と頼んでみてください。Claudeが情報の内容を見て、適切な形を選んでくれます。

2. 箇条書きメモ → 表に変換する実例

会議でとったバラバラなメモを渡すだけで、きれいな表が完成します。 こんなプロンプトで試してみてください。 

以下のメモを比較表にして。
列は「サービス名 / 月額料金 / 無料プランあり？ / 特徴」

・Notion：月1800円、無料あり、文書とデータベースが一体化
・Trello：月750円、無料あり、カンバン形式でシンプル
・Asana：月1500円、無料あり、タスクの依存関係が見える
・Monday.com：月2700円、無料なし、視覚的なダッシュボード

出てくる表のイメージ

| サービス名   | 月額料金 | 無料プラン | 特徴                     |
|-------------|---------|-----------|-------------------------|
| Notion      | 1,800円  | あり      | 文書とデータベースが一体化 |
| Trello      | 750円    | あり      | カンバン形式でシンプル    |
| Asana       | 1,500円  | あり      | タスクの依存関係が見える  |
| Monday.com  | 2,700円  | なし      | 視覚的なダッシュボード    |

3. 作った表をNotionやGoogle Docsに貼る

Claudeが出す表はMarkdown形式というシンプルな書き方です。 そのままコピーして、使いたいツールに貼ればOKです。

貼り付け手順

  1. Claudeの回答をコピー（Ctrl+A → Ctrl+C）
  2. NotionやGoogle Docsのページを開く
  3. Ctrl+V で貼り付ける
  4. 自動的に表として認識される（Notionはほぼ完璧。Docsもそのまま貼れる）
Excelに貼る場合は少し手間がかかります。Claudeに「CSV形式で出して」と頼むと、Excelで開きやすい形式になります。

4. 表を後から調整する

一度作った表も、会話を続けるだけで修正できます。追加や並べ替えも一言でOK。

よく使う調整の言い方

  • 「列を追加して。「使いやすさ（★1〜5）」も入れて」
  • 「料金の安い順に並べ替えて」
  • 「Notionの行だけ削除して」
  • 「一番おすすめの行に「◎」をつけて」
  • 「もう一列追加して。「こんな人に向いてる」という列を足して」
表が大きくなりすぎると読みにくくなります。列は5〜6個まで、行は10〜15個くらいを目安にするときれいです。

5. 実際に使える場面

競合比較表

「自社サービスと競合3社を、価格・機能・サポートで比べた表を作って」と頼むだけ。商談資料がすぐできます。

タスクリスト

「この会議メモから、担当者・期限・タスク内容の表を作って」。バラバラな宿題を一覧にまとめられます。

予算表

「来月の予算を、項目・予算額・実績・差異の表にまとめて」。数字を渡すだけで整理してくれます。

アンケート結果の整理

「このアンケートの自由記述を、肯定的意見・否定的意見・要望の3列に整理して」。大量のテキストも分類できます。

この回のまとめ
  • 「表にして」は横並び比較、「項目別に整理して」はカテゴリ分けに使う
  • 箇条書きメモをそのまま渡すだけで表が完成する
  • 作った表はコピーしてNotionやGoogle Docsにそのまま貼れる
  • 「列を追加して」「並べ替えて」と続けて調整できる
