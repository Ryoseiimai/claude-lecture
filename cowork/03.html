CO-WORK 03

仕事ごとに分ける
「プロジェクト」機能

所要時間:約30分 レベル:基本 必要なもの:Claude有料プラン(Pro以上)
この回のゴール
  • 「プロジェクト」機能が何者か分かる
  • 自分の仕事用のプロジェクトを1つ作れる
  • 同じ説明を毎回繰り返さなくて済むようになる

1. プロジェクトって何?

LESSON 02までで、Claudeとのやりとりに慣れてきたはず。 ただ、1つ困ったことがあります——毎回、自己紹介や前提情報を説明し直すのが面倒。

それを解決するのが「プロジェクト」機能です。 仕事ごと・案件ごとに「箱」を作って、その中で会話すれば、Claudeは毎回勝手に前提を思い出してくれます。

普通のチャット = 毎回「初対面」
プロジェクト内のチャット = 毎回「よく知った仲」

例えばこういう時に便利

  • 特定のクライアント(例:B社)について何度も相談する時
  • 継続案件(例:月刊の連載記事、毎週の会議)がある時
  • 自分の会社・事業について深く理解させた上で相談したい時
  • 参考資料(過去の議事録・仕様書)を入れて、それを踏まえて答えてほしい時
スクリーンショット:プロジェクト一覧画面(仕事ごとに箱が並んでいる)

2. プロジェクトの3つのパーツ

プロジェクトは、3つの要素でできています。

パーツ1:名前・アイコン

プロジェクトの名前と、ひと目で分かる説明。「A社案件」「noteの記事執筆」「経理の月次業務」など、自分が見てすぐ分かる名前にしておきます。

パーツ2:カスタム指示(説明書)

これが本丸。 Claudeに「このプロジェクトでは毎回こういう前提でやってね」と、あらかじめ教えておく場所です。

例えば、営業の人のプロジェクトなら:

【前提】
- 私は◯◯株式会社の営業担当
- 扱っている商材:中小企業向けの会計ソフト
- ターゲット:従業員10〜50人の会社

【返事のお願い】
- メールや提案書は、丁寧だけど堅すぎない感じで
- 根拠や数字は必ず添える
- 箇条書きで整理してくれると嬉しい

【禁止】
- 事実を盛らない。分からないことは「分からない」と書く

これを入れておけば、以後このプロジェクトの中では、毎回この前提で話が進みます。 「私は営業で〜」の説明は、もう不要。

パーツ3:資料置き場

プロジェクトに関係する資料(PDF・Word・Excel・テキストなど)を、あらかじめアップロードしておけます。

例えば:

  • 会社案内のPDF
  • 過去のメールのやりとり(コピペしたテキスト)
  • 商品カタログ
  • 社内マニュアル
  • クライアントとの議事録

資料を入れておけば、Claudeがそれを読んだ上で答えてくれます。 「この案件、過去のやりとりを踏まえて返信書いて」みたいな頼み方が、一発で通ります。

プロジェクトに入れる資料は、Claudeが読んで会話に使います。 機密情報や顧客の個人情報を入れる時は、会社の方針を確認してください。

3. プロジェクトを作ってみよう

手順

  1. Claude(claude.ai)にログイン
  2. 左のメニューにある「Projects(プロジェクト)」をクリック
  3. 「Create project(新規作成)」ボタンを押す
  4. プロジェクト名と説明を入力(例:「A社 提案業務」)
  5. 「Create」で作成
  6. プロジェクトの詳細画面に移動したら、右側の「Custom instructions」にカスタム指示を書く
  7. 資料があれば「Add content」でアップロード
  8. 準備完了!あとは左下の入力欄で、そのプロジェクトの中で会話開始
スクリーンショット:プロジェクト作成画面 + カスタム指示の入力欄

4. カスタム指示の書き方テンプレート

迷ったら、この型をコピペして、自分用に書き換えてください。

【私について】
- 所属:◯◯(会社名・部署・役割)
- 業務:◯◯(何をやっている人か)

【このプロジェクトの目的】
- 何のために作ったプロジェクトか(例:B社案件の提案書作成)
- 関係者:自分、B社の山田さん(広報担当)

【返事のお願い】
- トーン:◯◯(丁寧/カジュアル/ストレート)
- 長さ:基本◯◯字くらい
- 構成:箇条書き/表/文章、お好み
- 根拠や数字は必ず添える

【避けてほしいこと】
- 推測で事実を作らない
- 専門用語を使わない(特に◯◯の分野)
- 長すぎる前置きは省略

5. 実際の使用例

例1:営業のAさんのプロジェクト

プロジェクト名:「B社 提案業務」

カスタム指示:自分の会社の情報、B社の背景、過去のやりとりの要点

資料:自社の商品パンフ、B社のWebサイトの紹介文、過去メールの履歴

使い方の例:

  • 「今週、B社からこんな質問が来た。返信の下書きを書いて」
  • 「来週の提案会で、B社の課題にハマりそうな切り口を3つ考えて」
  • 「B社向けに、うちの商品Xのメリットを200字で整理して」

例2:ライターのBさんのプロジェクト

プロジェクト名:「月刊◯◯誌 連載」

カスタム指示:連載のコンセプト、毎回の文字数、読者像、自分の文体

資料:過去の掲載号、編集部からのレギュレーション

使い方の例:

  • 「今月のテーマ案を5つ出して」
  • 「決まったテーマで、冒頭500字だけ書いて」
  • 「書き上げた原稿、文字数と誤字だけチェックして」

6. プロジェクトを使うコツ

コツ1:最初は「雑に」作る

完璧なカスタム指示を最初から書こうとしなくて大丈夫。 使いながら「あ、これも書いておいた方がいいな」と気づいたら、その都度追記すればOK。

コツ2:多すぎる資料は逆効果

関係ない資料まで全部入れると、Claudeが迷います。 本当に関係のあるものだけを厳選してください。

コツ3:プロジェクトを分けすぎない

最初のうちは、「仕事」「プライベート」くらいの粒度で十分。 使い慣れてきたら、案件ごとに細かく分けていきます。

7. やってみよう

今日のうちに、1つだけでもプロジェクトを作ってみてください。

  1. 自分の仕事で、繰り返し発生する業務を1つ決める(例:メール返信、記事執筆、経理処理)
  2. その業務用のプロジェクトを作る
  3. カスタム指示にテンプレートをコピペ→自分用に書き換え
  4. 関係する資料(あれば)を2〜3個アップロード
  5. 試しに、そのプロジェクトの中で1回質問してみる
毎回の「自己紹介の手間」がなくなるので、使い始めるともう通常チャットには戻れなくなるはずです。
