INTRO 00

Claudeには3つの使い方がある。
あなたはどれから始める?

所要時間：約30分 レベル：超入門 必要なもの：とくになし
この回のゴール
  • Claudeには「3つの使い方」があることを知る
  • それぞれの違いと、向いている人が分かる
  • 自分はどれから始めるべきかが決まる

1. Claudeって、実は3種類ある

「ClaudeってAIでしょ? 話しかけて使うやつ」——だいたい合ってます。 でも実は、Claudeには3つの使い方があって、目的によって選ぶやつが変わります。

この回では、その3つ——「チャット」「コワーク」「コード」——の違いをざっくり掴みます。 ここが分かっていれば、これから続く16回の講座で迷いません(導入1回 + アプリ編8回 + パソコン編8回 = 全17回)。

その1
チャット
とにかく話しかける。質問して、返事をもらう。一番シンプル。
その2
コワーク
仕事の資料や連絡とつなげて、本格的に業務で使う。
その3
コード
パソコンに入れて、ファイルを自由に操作してもらう。

2. 「チャット」ってどんな使い方?

一番かんたん。ブラウザで claude.ai を開いて、話しかけるだけです。 LINEでAIと会話してる、みたいなイメージでOK。

スクリーンショット：claude.ai のチャット画面（シンプルな入力欄＋返事）

向いている人

  • AIを使うのが初めての人
  • ちょっとした質問や文章作成に使いたい人
  • スマホからでもパッと使いたい人

例えばこんな使い方

  • 「この英語のメール、日本語にして」
  • 「誕生日プレゼント、20代女性向けで5つ提案して」
  • 「風邪の時に食べるといいものって何?」
  • 「このアイデアどう思う?率直に意見ちょうだい」

料金

  • 基本は無料(1日に使える回数の制限あり)
  • もっと使いたい人は月約3,000円の有料プラン

3. 「コワーク」ってどんな使い方?

チャットがちょっと上達したら、次に出会うのが「コワーク」です。 実はこれも claude.ai の中にある機能で、仕事にガッツリ使うためのモードだと思ってください。

コワークは、3つの仕組みを組み合わせます。

  1. プロジェクト……仕事ごとに箱を分けて、関係する資料を1ヶ所に集める
  2. 資料作成……ClaudeがWord/Excel風の文書を作って、その場で直せる
  3. 外部アプリ連携……GmailやSlackやGoogleドライブとClaudeをつなぐ

これが揃うと、Claudeが「仕事のパートナー」として動き始めます。 「先週のメール見て、今週の予定と照らし合わせて」とか、普通に頼めます。

スクリーンショット：プロジェクト画面（仕事ごとに箱が分かれているイメージ）

向いている人

  • 仕事で毎日のように使いたい人
  • メール・議事録・資料作成を任せたい人
  • 複数の案件を並行して進めている人

例えばこんな使い方

  • 「A社案件の過去メール全部ふまえて、今回の返信を書いて」
  • 「この1時間の会議の録音を、議事録にまとめて」
  • 「売上データ入れたExcelを渡すから、来期の予測出して」
  • 「提案書のドラフト作って。相手はB社の広報担当」

料金

  • プロジェクト機能や連携機能は有料プラン(月約3,000円〜)がメイン
  • 個人事業主〜会社員まで、本気で使うならここから

4. 「コード」ってどんな使い方?

3つ目は「Claude Code」。これはブラウザじゃなくて、自分のパソコンに直接入れて使うツールです。 いわゆる「プログラマー向け」と思われがちですが、じつは事務作業にもめちゃくちゃ使えるやつです。

違いを一言で言うと——チャットとコワークは「話しかけて答えをもらう」モード。 コードは「自分のパソコンを直接いじってもらう」モードです。

スクリーンショット：Claude Code の画面（黒い画面に文字を打って動かすイメージ）

向いている人

  • プログラマー・エンジニア
  • Excelや大量のファイル処理を自動化したい人
  • 「パソコンにやらせたい作業」がある人

例えばこんな使い方

  • 「このフォルダの中のPDF100枚、全部表にまとめて」
  • 「ウェブサイトのここを直して、ついでにバックアップ取って」
  • 「毎朝9時にニュースを集めて、メールで送って」
  • 「このプログラムのバグ、どこにあるか探して直して」

料金

  • Claude Code自体は無料でインストールできる
  • 動かすのに有料プラン(Claude Pro等)があると便利

6. 自分はどれから始めればいい?

「結局、自分はどれを使えばいい?」という人のために、1分で分かる診断を用意しました。

Q1. AIを触ったことはありますか?

→ ないなら チャット から。
→ あるなら Q2 へ。

Q2. 仕事で毎日使いたいですか?

→ 使いたいなら コワーク へ。
→ 使わない(プライベート中心)なら チャット のままでOK。

Q3. パソコンの中のファイルを自動で処理したい?

→ したいなら コード も覚える価値あり。
→ しないなら コワーク だけで十分。

タイプ別おすすめ

【タイプA】まずはAIに慣れたい人
チャットから。アプリ編のLESSON 01〜02だけでもOK。1時間で基本が分かります。
【タイプB】仕事でちゃんと使いたい人
コワークまでやりましょう。アプリ編の全8回でメール・議事録・資料作成が自動化できます。
【タイプC】プログラムやファイル処理も任せたい人
コードも必須。アプリ編 → パソコン編 の順で全17回やれば、AI全方位使いこなせます。

7. この講座の進め方

この講座は、順番に進めれば初心者でも使えるようになる構成です。

  1. アプリ編 LESSON 01〜02：登録と伝え方のコツ。ここが全部の土台。
  2. アプリ編 LESSON 03〜08：コワークの機能で仕事に使う。
  3. パソコン編 LESSON 01〜08：コードで本格的に自動化する。

1回あたり約30分。全部で約8時間くらいのボリュームです。 毎日1回ずつ進めれば2週間ちょっとで完走できます。

最初から全部理解する必要はなし。 「あ、こういうことできるんだ」くらいの感覚で進めてOK。使ってるうちに馴染みます。
